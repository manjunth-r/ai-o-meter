## Store Listing Copy

### Short Description (Max 132 chars)
Real-time, 100% client-side AI content likelihood meter with an instant Icon Spectrum and transparent per-signal breakdown.

### Detailed Description
AI-o-Meter gives you an instant, privacy-first estimate of whether the content on any webpage was written by a human, assisted by AI, or fully generated by an LLM.

Unlike opaque black-box tools that require copy-pasting text into third-party sites, AI-o-Meter runs **100% locally in your browser** with zero network latency, zero data collection, and a transparent per-signal breakdown so you can understand exactly *why* a score was given.

#### Key Features:
- **Icon Spectrum at a Glance:** Instantly visualizes whether text leans Human, Mixed, or Robot with a sliding indicator dot and dynamic color highlighting.
- **6-Signal Transparent Breakdown:**
  1. *Burstiness:* Analyzes sentence-length variation and natural writing cadence.
  2. *AI Cliché & Buzzword Density:* Matches against a curated dictionary of 180+ overused LLM patterns ("delve into", "rich tapestry", "testament to", etc.).
  3. *Vocabulary Diversity:* Computes rolling Type-Token Ratio (TTR) to detect flat repetition.
  4. *Structural Tells:* Evaluates em-dash frequency, formulaic enumeration ("Firstly / Secondly"), and bullet patterns.
  5. *Formality & Contraction Ratio:* Distinguishes natural conversational contractions from stiff uncontracted prose.
  6. *Transitional Opener Repetition:* Detects repetitive paragraph starter tics ("Furthermore,", "Moreover,").
- **Dynamic Badge Indicator:** Toolbar badge automatically displays the AI likelihood percentage and color status for the active tab.
- **Manual Evaluation Playground:** Paste custom drafts or toggle sample benchmarks to test any text in real time.
- **100% Client-Side & Private:** Your reading and browsing text never leaves your device. No backend servers, no analytics, no external API calls.

## Permissions Justification

| Permission / Host | Why It Is Needed (Chrome Review Justification) |
|---|---|
| `activeTab` | Required to scan the visible text of the active webpage when the user opens the AI-o-Meter popup. |
| `tabs` | Required to extract the active tab's domain name and title to display in the header, and to associate badge scores with their respective tabs. |
| `storage` | Required to cache computed scores per active tab session so the extension does not re-compute heuristics unnecessarily on every popup open. |
| `scripting` | Used as a fallback execution mechanism to extract main content text on dynamic pages where content scripts are awaiting injection. |
| `<all_urls>` | Required so the content script can evaluate article text across any news, blog, or documentation website the user visits. |

## Privacy & Data Use Disclosure

- **Does this extension collect or transmit personal data?** No.
- **Does this extension use remote servers or cloud AI APIs?** No. All heuristic analysis and tokenization are performed locally inside the browser.
- **Single Purpose:** Analyze webpage text for AI content likelihood and present an explanatory breakdown to the user.
