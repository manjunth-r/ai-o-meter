**Detailed Description** [REQUIRED]
<!-- Max 16,000 characters -->
AI-o-Meter is a lightweight, privacy-first browser extension that estimates whether the content on any webpage was written by a human, assisted by AI, or generated by an LLM.

Unlike opaque black-box tools that require copy-pasting text into third-party sites, AI-o-Meter runs 100% locally in your browser with zero network latency, zero data collection, and a transparent per-signal breakdown so you can understand exactly why a score was given.

Key Features:
- Icon Spectrum at a Glance: Instantly visualizes whether text leans Human, Mixed, or Robot with a sliding indicator dot and dynamic color highlighting.
- 6-Signal Transparent Breakdown:
  1. Burstiness: Analyzes sentence-length variation and natural writing rhythm.
  2. AI Cliché & Buzzword Density: Matches against a curated dictionary of 180+ overused LLM patterns ("delve into", "rich tapestry", "testament to", etc.).
  3. Vocabulary Diversity: Computes rolling Type-Token Ratio (TTR) to detect flat repetition.
  4. Structural Tells: Evaluates em-dash frequency, formulaic enumeration ("Firstly / Secondly"), and bullet patterns.
  5. Formality & Contraction Ratio: Distinguishes natural conversational contractions from stiff uncontracted prose.
  6. Transitional Opener Repetition: Detects repetitive paragraph starter tics ("Furthermore,", "Moreover,").
- Dynamic Toolbar Badge: Badge automatically displays the AI likelihood percentage and color status for the active tab.
- Interactive Evaluation Playground: Paste custom drafts or test benchmark presets directly in the popup.
- 100% Client-Side & Private: Your reading and browsing text never leaves your device. No backend servers, no analytics, no external API calls.

How to Use:
1. Pin the AI-o-Meter icon to your Chrome toolbar.
2. Browse to any article, blog post, or documentation page.
3. Check the toolbar badge for an instant score estimate.
4. Click the icon to view the full Icon Spectrum, likelihood verdict, and 6-signal breakdown.

Privacy & Trust:
AI-o-Meter processes all content on-device. No text, URLs, or browsing habits are ever collected, stored remotely, or transmitted.

## Permissions Justification

| Permission | Type | Justification |
|---|---|---|
| `activeTab` | permissions | Required to access and evaluate the text content of the active webpage when the user opens the AI-o-Meter popup. |
| `tabs` | permissions | Required to read the active tab's domain name for header labeling and manage badge indicator updates per tab. |
| `storage` | permissions | Required to cache computed heuristic scores in session storage (`chrome.storage.session`) so scores persist seamlessly during active browsing without re-computing on every popup toggle. |
| `scripting` | permissions | Required as a fallback mechanism to safely extract text on dynamically loaded single-page applications. |
| `<all_urls>` | host_permissions | Required so the content script can evaluate article text across any news, blog, or documentation website the user visits. |

## 🚀 Step-by-Step Submission Guide for Chrome Web Store

1. **Log in to Developer Dashboard:**
   Go to [https://chrome.google.com/webstore/devconsole](https://chrome.google.com/webstore/devconsole).

2. **Upload Package:**
   - Click **Add new item**.
   - Upload `dist/ai-o-meter-v1.0.0.zip`.

3. **Fill Out Store Listing:**
   - Copy the **Title**, **Short Description**, and **Detailed Description** from Section 1 above.
   - Upload icon (`icons/icon-128.png`).
   - Upload Screenshots from `test/store-showcase.html` (1280×800).
   - Select Category: **Productivity**.

4. **Privacy Tab:**
   - Set Single Purpose to: `Analyzes webpage text on-device to estimate AI content likelihood and displays an explanatory heuristic breakdown.`
   - Paste the Permissions Justifications from the table above for `activeTab`, `tabs`, `storage`, `scripting`, and `<all_urls>`.
   - Set Data collection to **No** (all checkboxes cleared, all 3 certification boxes checked).
   - Provide Privacy Policy URL: `https://github.com/manjunth-r/ai-o-meter/blob/main/PRIVACY.md`.

5. **Submit for Review:**
   - Click **Submit for review**. Standard review typically takes 24–48 hours.
